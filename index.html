Software / Desktop Application

RMM Lab Komputer — Real-Time Remote Monitoring

Sistem RMM (Remote Monitoring & Management) ini dirancang untuk mengatasi kendala instruktur lab komputer sekolah maupun kampus dalam mengawasi puluhan komputer siswa secara terpusat tanpa hambatan latensi.

Fitur Unggulan Sistem:
  • Live Grid Screen Broadcast: Menampilkan siaran langsung layar hingga 40+ client secara bersamaan via WebRTC peer connection.
  • Remote Lock & Focus Mode: Mengunci input keyboard dan mouse siswa saat sesi penjelasan materi berlangsung.
  • Broadcast Message & Assets: Mengirimkan pengumuman serentak atau distribusi file materi secara instan.
  • Remote Terminal Command: Menjalankan script diagnostik atau restart/shutdown massal dari workstation server.
  • Audit Aktivitas Real-Time: Pencatatan riwayat aplikasi aktif dan koneksi client berbasis Socket.IO event handler.
Teknologi & Arsitektur:
Electron.js (Host & Client GUI) Node.js (Backend Engine) Socket.IO (Signaling & RPC) WebRTC (Low-Latency Video Stream) SQLite (Local Logs)
Status: Production Ready

Web Application & Frontend

NexShop — Platform E-Commerce Modern

NexShop menghadirkan pengalaman belanja online yang responsif, cepat, dan intuitif. Dibangun dengan pendekatan antarmuka modern yang memadukan Bootstrap 5 kustom dan JavaScript murni untuk fluiditas interaksi maksimal.

Fitur Utama Platform:
  • Katalog Dinamis & Filter Instan: Penyaringan produk berdasarkan harga, kategori, dan rating tanpa me-reload halaman.
  • Keranjang Belanja Interaktif (Offcanvas): Mengatur kuantitas item, kalkulasi otomatis diskon & ongkir secara real-time.
  • Penyimpanan Sesi (LocalStorage): State keranjang tetap tersimpan aman saat pengguna menutup atau me-refresh browser.
  • Checkout Multi-Langkah Responsif: Form pemesanan terintegrasi dengan validasi input yang ketat dan ramah pengguna.
  • Desain Mobile-First 100%: Tampilan dioptimalkan untuk navigasi satu tangan di layar smartphone.
Teknologi yang Digunakan:
HTML5 Semantic Bootstrap 5 Components Vanilla JavaScript (ES6 Modules) REST API Integration CSS Custom Variables
Status: Live Demo & Code Open
